## A Note on Hardware RAID and Why It Matters

The lower-tier plans list "Software/BIOS" RAID, while the upper tiers specify "Hardware RAID + BBU." That BBU — battery backup unit — is the difference between a server that survives a power blip with its write cache intact and one that doesn't. For backups, archives, or anything where data integrity actually matters, the upgrade to the $202/mo dual E5-2697v3 plan (or above) is where the lineup starts feeling like real enterprise hardware rather than repurposed desktop-grade gear.

The 1 TB and 2 TB NVMe storage on those tiers also matters more than the raw capacity suggests. NVMe's IO advantage over SATA SSD compounds when you're running concurrent database workloads, and the hardware RAID controller takes that load off the CPU. If you're shopping the upper end of the lineup, those two specs are the actual differentiators — not the core count, which is mostly a marketing number past a certain point.
